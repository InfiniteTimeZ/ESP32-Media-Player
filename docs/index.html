ESP32 Media Player

Install the ESP32 Media Player firmware directly from your browser. No PlatformIO or ESP32 development environment is required.

Supported hardware: This firmware is intended for the reference ELECROW CrowPanel Advance 4.3-inch ESP32-S3 build using 16 MB flash and 8 MB PSRAM.

Before installing

  1. Connect the display to your computer over USB.
  2. Close the ESP32 Media Sync desktop companion and any serial monitor.
  3. Click Install Firmware.
  4. Select the ESP32-S3 serial device when your browser asks.
  5. Wait for flashing to complete before disconnecting the display.
This browser does not support the required Web Serial features. Try a current desktop version of Chrome or Edge. Firmware installation requires a secure HTTPS page.

Firmware version: v0.1.1
